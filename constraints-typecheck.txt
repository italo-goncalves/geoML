# The versions the type check was written against.
#
# Pinning the dev extra pins the checker; it does not pin what the checker
# reads. Most of pyright's findings come from the *stubs* of the runtime
# dependencies, so a fresh CI install of the latest scipy or zarr reports
# things this machine's older ones do not -- 88 of them the day this file
# was written, none of which were about geoML's own code.
#
# So the typecheck job installs against these, and the library's own
# dependency list stays floored rather than pinned: a user should get
# current versions, and only the gate needs a fixed world to judge in.
#
# Raising one of these is how upstream drift gets noticed on purpose, at a
# moment somebody chose. The SciPy entry has already earned its keep: the
# `Sobol(seed=)` rename showed up this way, and was fixed before it broke
# anything (geoml/stats/random.py, `sobol_engine`).

pandas==2.2.3
scipy==1.15.3
